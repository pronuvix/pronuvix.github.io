Privacidade e segurança

Os teus dados. No teu dispositivo.

Sincronização direta entre dispositivos

Os dispositivos autorizados trocam registos financeiros diretamente através da rede local, quando suportado. Não é necessária uma base de dados financeira central da Zelunvo.

Backup opcional não é sincronização

A cópia de segurança na cloud, quando ativada, guarda uma cópia cifrada para recuperação. É independente da sincronização direta.

Protege os teus dispositivos

Protege o acesso aos dispositivos e guarda a chave de recuperação num local seguro.

Armazenamento local

Os teus registos financeiros são armazenados nos teus dispositivos. A Zelunvo não depende de uma base de dados financeira central.

Backups cifrados

Os backups opcionais na cloud são concebidos para ser cifrados antes do envio. Guarda a chave de recuperação separadamente.

Partilha familiar

Partilha apenas com dispositivos e contas autorizados, quando suportado.

Conectividade

Publicidade, cotações e serviços online opcionais podem exigir Internet.
