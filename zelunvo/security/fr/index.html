Confidentialité et sécurité

Vos données. Sur votre appareil.

Synchronisation directe entre appareils

Les appareils autorisés échangent directement les données sur le réseau local, si disponible. Aucune base financière centrale Zelunvo n’est nécessaire.

Sauvegarde facultative distincte

La sauvegarde cloud activée conserve une copie chiffrée pour la restauration, indépendamment de la synchronisation directe.

Protégez vos appareils

Protégez l’accès aux appareils et conservez la clé de récupération en lieu sûr.

Priorité au stockage local

Les données financières sont conçues pour rester principalement sur l’appareil.

Sauvegardes chiffrées

Les sauvegardes cloud facultatives sont conçues pour être chiffrées avant envoi. Conservez la clé séparément.

Partage familial

Partagez uniquement avec les appareils et comptes autorisés, si disponible.

Connectivité

La publicité, les cours et les services facultatifs peuvent nécessiter Internet.
